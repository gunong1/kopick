# KOPICK 제품 설계 문서 (MVP)

> 핵심 철학: "가장 싼 상품이 아니라, 가장 합리적인 상품을 찾게 해준다"
> KOPICK은 AI 챗봇이 아니라 **검색 결과와 상품 랭킹**이 핵심인 서비스다. AI는 뒷단(데이터 정리·리뷰 분석·점수 계산)에서만 쓰인다.

핵심 플로우: **상품 검색 → 상품 목록 → 조건별 필터 → 상품 상세 → KOPICK Score → 구매처 이동**

---

## 1. KOPICK MVP 핵심 기능

| 기능 | 설명 |
|---|---|
| 카테고리 검색/탐색 | 검색어 입력 또는 카테고리 클릭으로 상품군 진입 |
| 다중 랭킹 뷰 | 종합 / 가성비 / 성능 / 리뷰 만족도 / 배터리 / 가격대별 / 용도별 탭 |
| 필터 | 가격대, 브랜드, 핵심 스펙, 용도 태그 |
| 상품 상세 + KOPICK Score | 총점 + 세부 항목 점수(성능/가성비/리뷰만족도/배터리/AS 등) breakdown |
| 리뷰 AI 요약 | 여러 쇼핑몰 리뷰를 모아 긍/부정 키워드·요약 문장 생성 (뒷단 AI, 사용자와 대화 X) |
| 상품 비교 | 2~3개 상품 스펙/점수 나란히 비교 |
| 구매처 이동 | 쿠팡/네이버쇼핑 등으로 제휴 딥링크 이동 |
| (내부) 데이터/점수 관리 어드민 | 상품 데이터 적재, 가중치 조정, 이상치 검수 — 사용자 비노출 |

MVP에 로그인, 챗봇, 개인화, 커뮤니티는 포함하지 않는다 (10번 항목 참조).

## 2. 전체 UX 흐름

```
[홈/카테고리 허브]
   │  검색어 입력 또는 카테고리 클릭
   ▼
[상품 리스트 페이지] ──(랭킹 탭 전환: 종합/가성비/성능/리뷰/배터리/가격대별/용도별)
   │        └─(필터 적용: 가격대·브랜드·스펙·용도)
   │  상품 카드 클릭
   ▼
[상품 상세 페이지]
   │  KOPICK Score 확인 (총점 + 항목별 breakdown + 근거 요약 + 리뷰 요약)
   │  (선택) 비교함에 담기 → [비교 페이지]
   │  "구매하러 가기" 클릭
   ▼
[판매처 선택 (쿠팡/네이버쇼핑 등, 가격 병기)]
   ▼
외부 쇼핑몰로 이동 (제휴 딥링크, 새 탭) → 구매는 전적으로 외부에서 발생
```

보조 흐름:
- 홈에서 "이번 주 KOPICK 추천" 큐레이션 → 상세 페이지로 바로 진입 (검색 스킵 경로)
- 리스트에서 여러 상품 체크 → 비교 페이지로 이동
- 검색 결과 없음 → 유사 카테고리 추천

## 3. 필요한 화면 목록

1. 홈 / 카테고리 허브
2. 상품 리스트 (검색 결과, 랭킹 탭 + 필터 포함) — **가장 중요한 화면**
3. 상품 상세 (KOPICK Score 포함)
4. 상품 비교
5. 카테고리 전체 목록
6. 빈 상태 / 검색결과 없음
7. (내부용) 어드민 대시보드 — 상품 데이터 관리, 점수 파라미터 조정, 이상치 큐

로그인/마이페이지/찜하기는 MVP 제외 (10번 참조).

## 4. 각 화면의 UI 구조

### 4.1 홈 / 카테고리 허브
- 상단: 검색바 (최우선 CTA, 화면 최상단 고정)
- 인기 카테고리 그리드 (아이콘 + 카테고리명, 초기엔 1~2개만 활성)
- "이번 주 KOPICK 추천" 큐레이션 배너 — 신뢰 요소, 에디토리얼 색채
- 카테고리별 Top 3 미리보기 카드 (클릭 시 리스트 페이지로)

### 4.2 상품 리스트 페이지
- 상단: 카테고리명 + 상품 수 + 검색바
- **랭킹 탭 바** (가로): 종합 | 가성비 | 성능 | 리뷰 만족도 | 배터리 | 가격대별 | 용도별
- 좌측(모바일: 상단 드로어) 필터 패널: 가격 슬라이더, 브랜드 체크박스, 핵심 스펙 필터, 용도 태그
- 상품 카드 리스트: 순위 뱃지(#1, #2…), 대표이미지, 상품명/브랜드, 가격, **KOPICK Score**, 핵심 지표 미니배지 3개, 리뷰 별점·개수, "비교 담기" 체크박스
- 데이터 신뢰도 낮은 상품은 "정보 확인 중" 배지 표시 (스펙 결측/리뷰 절대부족)

### 4.3 상품 상세 페이지
- 이미지 갤러리
- 상품명 / 브랜드 / 현재가 / 최근 가격 추이 간단 표시
- **KOPICK Score 원형 게이지** (예: 87점, "매우 합리적" 등급 라벨)
- 항목별 점수 레이더 차트 (성능/가성비/리뷰만족도/배터리/AS 등, 카테고리에 따라 축 달라짐)
- "왜 이 점수인가" AI 요약 2~3문장 (근거 데이터 기반, 과장 없이)
- 스펙 표 (정형 데이터)
- 리뷰 AI 요약 카드: 긍정/부정 키워드, 요약 문장, 원본 리뷰 개수·출처(쿠팡/네이버 등) 표기
- "이 가격대 다른 대안" 추천 슬라이더
- 하단 고정 CTA 바: 쇼핑몰별 가격 병기 + "구매하러 가기" 버튼 → 새 탭 아웃링크

### 4.4 비교 페이지
- 선택 상품(2~3개)을 열로, 스펙/점수 항목을 행으로 하는 비교 테이블
- 각 열 하단에 구매처 이동 버튼

### 4.5 어드민 (내부용, 최소 기능)
- 상품 목록 + 원본 데이터 소스 상태(마지막 수집 시각 등)
- 카테고리별 가중치 프로필 조정 UI (초기엔 config 파일/스프레드시트로 대체 가능)
- 이상치·결측 데이터 플래그 큐

## 5. 상품 데이터 구조

```
Category
- id, name, slug
- spec_schema: [{ key, label, type, unit, higher_is_better }]   # 카테고리별 동적 스펙 정의
- score_weight_profiles: { comprehensive: {...}, cost_efficiency: {...}, performance: {...}, ... }

Product
- id, category_id, name, brand, model_code
- images: [url]
- specs: { [spec_key]: value }              # spec_schema 기준 동적 JSON
- price_current: number
- price_history: [{ date, price }]
- retailers: [
    { name: "coupang" | "naver", product_url, affiliate_url, price, in_stock, last_checked_at }
  ]
- review_summary: {
    avg_rating, review_count,
    source_breakdown: { coupang: { rating, count }, naver: { rating, count } }
  }
- review_ai_summary: { positive_keywords[], negative_keywords[], summary_text, updated_at }
- as_info: { warranty_months, service_center_count, brand_as_grade }
- kopick_score: {
    total, grade,
    sub_scores: { performance, cost_efficiency, review_satisfaction, battery, as_service },
    version, computed_at
  }
- data_confidence: 0~1                       # 스펙/리뷰 결측 정도 반영
- status: active | deprecated

ReviewRaw (AI 요약 파이프라인 입력용, 별도 저장)
- id, product_id, source, rating, text, date, helpful_count

PriceSnapshot (가격 이력, 가성비/최저가 신뢰용)
- product_id, retailer, price, captured_at
```

카테고리마다 스펙이 다르므로 `specs`는 JSONB로 저장하고, `spec_schema`가 그 필드들의 의미(단위, 높을수록 좋은지 여부)를 정의한다.

## 6. KOPICK Score 초기 알고리즘

**원칙: 처음부터 ML이 아니라 규칙 기반 가중합으로 시작한다.** 카테고리 내 상품군 기준으로 각 지표를 정규화한 뒤 가중합한다.

```
KOPICK Score = Σ (sub_score_i × weight_i)     (0~100로 정규화)
```

### 6.1 서브 스코어 정의 (카테고리 공통 골격)

| 서브 스코어 | 산출 방식 |
|---|---|
| 성능 (Performance) | 핵심 스펙(예: 흡입력)을 카테고리 내 percentile/min-max 정규화 |
| 가성비 (Cost-efficiency) | `performance_score / normalized_price` 를 재정규화 — 단순 저가가 아니라 "가격 대비 성능" |
| 리뷰 만족도 | 평점의 **베이지안 가중평균**(리뷰 수 적은 상품이 5점으로 왜곡되는 것 방지) + AI 감성분석으로 부정 리뷰 비중 반영 |
| 내구성/AS | 무상보증기간, 서비스센터 수, 브랜드 AS 등급(초기엔 브랜드별 등급표로 근사) |
| 배터리 (해당 카테고리 한정) | 사용시간, 충전시간, 배터리 탈부착 여부 정규화 |

### 6.2 신뢰도 페널티
- 스펙 결측/리뷰 절대부족 상품은 `data_confidence`로 총점 discount, "정보 확인 중" 배지 노출 (랭킹 조작이 아니라 데이터 품질 문제로 처리)

### 6.3 광고와의 분리 원칙 (매우 중요)
- `ad_boost` 등 광고 관련 필드는 **`kopick_score` 계산에 절대 포함하지 않는다.**
- 광고 상품은 랭킹 리스트와 분리된 별도 "스폰서" 슬롯(명확히 라벨 표시)에만 노출 가능. 점수/순위 조작 금지.

### 6.4 고도화 방향 (MVP 이후)
- 사용자 클릭/구매전환/후속 리뷰 데이터로 가중치를 회귀/베이지안 업데이트 방식으로 보정 → 처음부터 시도하지 않음

## 7. 카테고리별 점수 계산 방식 (랭킹 탭의 실제 구현 원리)

**"여러 랭킹 탭"은 사실 동일한 서브 스코어 데이터셋 위에서 가중치 프리셋만 바꾼 재정렬 뷰다.** 이렇게 설계하면 계산 로직이 단순해지고 유지보수가 쉽다.

예시 (무선청소기 카테고리):

| 탭 | 가중치 (성능/가성비/리뷰만족도/배터리/AS) |
|---|---|
| 종합 | 30 / 20 / 20 / 20 / 10 |
| 가성비 | 15 / 60 / 10 / 10 / 5 |
| 성능 | 60 / 10 / 15 / 10 / 5 |
| 리뷰 만족도 | 10 / 10 / 65 / 10 / 5 |
| 배터리 | 15 / 10 / 10 / 60 / 5 |
| 가격대별 | 가격 구간으로 먼저 그룹핑 → 구간 내에서 "종합" 가중치로 정렬 |
| 용도별 (예: 반려동물/원룸/대형평수) | 용도 태그에 맞는 스펙 필터 선적용 + 해당 용도 전용 가중치 프리셋 적용 |

카테고리를 추가할 때는 `spec_schema`와 `score_weight_profiles`만 새로 정의하면 되고, 점수 계산 엔진 코드는 공통으로 재사용한다.

## 8. 초기에 시작할 상품 카테고리

**선정 기준**: ① 스펙이 정형화되어 있음 ② 가격 편차가 크고 "싸게 샀다가 후회"하는 카테고리 ③ 리뷰/스펙 데이터 소싱이 쉬움(쿠팡/네이버 리뷰 다수) ④ 제휴 커미션이 매력적(가전군).

**추천: 무선청소기 단일 카테고리로 시작.**
- 10만원대~100만원대 이상까지 가격 편차가 크고, "저가=후회" 스토리가 명확해 KOPICK 철학을 증명하기 좋음
- 스펙(흡입력, 배터리, 무게, 먼지통 용량 등)이 표준화되어 있어 점수 설계가 쉬움
- 알고리즘/UX를 하나의 카테고리에서 충분히 검증한 뒤, 2차로 공기청정기·로봇청소기 등 유사 가전으로 확장

처음부터 여러 카테고리를 동시에 벌리지 않는다.

## 9. 외부 쇼핑몰 연동 구조

```
[쿠팡파트너스 API] ─┐
[네이버쇼핑 검색 API] ─┼─▶ [수집 배치(cron)] ─▶ [상품 매칭/정규화] ─▶ Product/PriceSnapshot 테이블
                    │        (모델명/스펙 유사도로
                    │         동일 상품 매핑)
                    ▼
              가격 재조회 (초기 1일 1~2회)
```

- **데이터 수집**: 초기엔 공식 API(쿠팡파트너스 Open API, 네이버쇼핑 검색 API) 우선 — 자체 크롤링보다 ToS 준수 및 안정성 확보
- **상품 매핑**: 동일 상품이 쿠팡/네이버에 다른 ID로 존재 → 모델명/스펙 유사도로 하나의 내부 `product_id`에 여러 `retailers[]`를 연결
- **구매처 이동**: 상세 페이지 "구매하러 가기" 클릭 시, 서버사이드에서 쿠팡파트너스 딥링크 생성 → 자체 `/go/{product_id}?retailer=coupang` 리다이렉트 엔드포인트 경유(클릭 트래킹 및 이후 A/B 테스트용) → 새 탭으로 실제 쇼핑몰 이동
- **재고/품절 처리**: `last_checked_at` 기준 오래된 상품은 "가격 확인 필요" 배지, 품절 감지 시 랭킹에서 제외 또는 하단 배치

## 10. MVP에서 반드시 제외해야 할 기능

- AI 챗봇/대화형 인터페이스 (핵심 원칙 위배)
- 로그인/회원가입, 마이페이지, 찜하기·가격하락 알림
- 사용자 직접 리뷰 작성(UGC) — 초기엔 외부 리뷰 집계·분석만
- 개인화 추천(협업 필터링 등) — 초기 데이터로는 무의미
- 다중 카테고리 동시 오픈
- 자체 실시간 멀티 쇼핑몰 크롤러 고도화 — 공식 API로 시작
- 커뮤니티/QnA 기능
- 네이티브 앱 — 모바일 웹(+PWA 정도)으로 충분
- 판매자 입점/자체 결제 — KOPICK은 항상 비교·랭킹까지만, 결제는 외부로 이동
- 고도화된 ML 랭킹 모델 — 규칙 기반으로 시작

## 11. 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| Frontend | Next.js (React) + TypeScript + Tailwind CSS | SEO(검색엔진 유입이 핵심 채널)를 위한 SSR/SSG 필수, Vercel 무료 배포 |
| Backend | Next.js API Routes | 1인 개발 초기엔 풀스택 단순화 |
| DB | PostgreSQL (Supabase) | 무료 티어, Auth/Storage 확장 용이, `specs`는 JSONB로 카테고리별 동적 스키마 처리 |
| 배치/파이프라인 | Node.js 스크립트 + Vercel Cron / GitHub Actions scheduled workflow | 가격 수집, 점수 재계산 |
| AI 활용 | Claude API (배치용, 저비용 모델) | 리뷰 요약, 스펙 정규화 보조 — 사용자 대면 챗봇 아님 |

| 모니터링 | Vercel Analytics + Sentry (무료 티어) | |

## 12. 1인 창업자가 저비용으로 MVP 만드는 방법

1. **상품 수를 최소화**: 무선청소기 카테고리 실제 판매 상위 30~50개 모델만 우선 큐레이션 (데이터 품질 > 데이터 양)
2. **알고리즘은 코드 전에 스프레드시트로 시뮬레이션**: 가중치·정규화 방식을 엑셀에서 먼저 검증 후 코드로 이식
3. **무료/저비용 인프라**: Vercel(Hobby) + Supabase(Free tier) — 초기엔 월 비용 거의 0에 가깝게 운영 가능
4. **API 비용 관리**: 네이버쇼핑 검색 API 무료, 쿠팡파트너스는 수익공유형(무료), AI는 배치성 호출만이라 저비용 모델(Haiku 등)로 충분
5. **디자인은 직접**: Tailwind + shadcn/ui로 디자이너 없이 제작
6. **검증 우선순위**: 기능을 늘리기보다 "랭킹이 실제로 합리적인가"를 소수 지인/커뮤니티에 직접 검증받는 데 시간을 쓴다 — 이것이 KOPICK의 핵심 자산이므로

## 첫 번째 개발 단계: 실제로 무엇부터 만들 것인가 (우선순위)

1. **카테고리·스펙·가중치 설계 (스프레드시트)** — 무선청소기 `spec_schema`, 서브 스코어 정의, 가중치 프리셋(종합/가성비/성능/배터리/리뷰) 확정. 코드 이전에 반드시 먼저.
2. **상품 데이터 30~50개 시딩** — 쿠팡파트너스/네이버쇼핑 API로 가격·기본정보 수집, 스펙은 제조사 페이지 참고해 반자동 입력 → Postgres 적재
3. **KOPICK Score 계산 로직 구현** — 배치 스크립트로 서브 스코어 정규화 + 가중합, 스프레드시트 결과와 대조 검증
4. **상품 리스트 페이지 구현** — 랭킹 탭 + 필터, 서비스의 심장이므로 최우선 UI
5. **상품 상세 페이지 구현** — 점수 breakdown, 리뷰 요약, 구매처 버튼
6. **쿠팡파트너스 딥링크 연동 + 클릭 트래킹 리다이렉트 엔드포인트**
7. **홈/카테고리 허브 페이지** — 진입점
8. **리뷰 AI 요약 배치 파이프라인 연동**
9. **가격 재수집 cron 배치 및 데이터 갱신 자동화**
10. **소수 사용자 비공개 테스트** → 랭킹 결과 피드백 수집 → 가중치 보정
11. **SEO 최적화 및 정식 오픈** — 메타태그, sitemap, SSR 확인
